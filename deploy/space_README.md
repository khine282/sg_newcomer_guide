# SG Newcomer Guide

Ask about work, CPF, housing, transport or healthcare in Singapore, in English
or Burmese. Answers come only from official documents and list their sources.

Source code, evaluation and how it was built:
https://github.com/khine282/sg_newcomer_guide

Learning project. Always confirm information on the official websites.
The demo uses the Gemini free tier, so questions are limited per visitor and
per day. After 48 hours without visitors the Space sleeps and takes a few
minutes to wake up.
